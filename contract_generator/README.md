# Генератор файлов для тестирования импорта договоров

Отдельная программа формирует один XLSX с указанным количеством строк ДБЗ. Заголовки и порядок колонок разделяются с обработчиком импорта приложения, поэтому файл готов к загрузке через «Импорты → Новый импорт → Договоры».

Запуск из корня репозитория:

```powershell
python -m contract_generator --count 10
```

По умолчанию XLSX создаётся в `generated_imports`. Можно задать файл, воспроизводимое зерно случайных данных и сценарий:

```powershell
python -m contract_generator --count 25 --output .\demo-contracts\contracts.xlsx --scenario mixed --seed 42
```

Сценарии:

- `valid` — строки с уникальными ДБЗ и корректными полями.
- `mixed` — рабочие строки вместе с повторным ДБЗ, отрицательной суммой, пустым ФИО и ошибочным ИИН для проверки сообщений об ошибках.
- `duplicate-contract` — первая строка корректна, остальные повторяют её номер ДБЗ.
- `invalid-iin`, `negative-amount`, `missing-name` — строки с выбранной ошибкой.
- `reused-borrower` — разные ДБЗ с одним ИИН и ФИО.

`--count` / `-n` задаёт количество строк от 1 до 99999. `--output` / `-o` задаёт путь к XLSX. Также доступны `--seed` и `--start-date YYYY-MM-DD`. Существующий файл не перезаписывается.

Данные синтетические: ИИН имеют тестовый нулевой префикс, а имена помечены словом «ТЕСТОВЫЙ». Пустые справочные поля не требуют предварительного создания КА, кредиторов или договоров цессии.

Генератору нужен Python и `openpyxl` (уже указан в корневом `requirements.txt`). Чтобы запускать его отдельно, установите зависимости:

```powershell
python -m pip install -r contract_generator\requirements.txt
```
